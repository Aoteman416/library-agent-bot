# 简历面试 100 问（基于《简历-软件开发》定制）

> **适用对象**：吴镇旭 / 沈阳工学院 计算机科学与技术 2026 届应届生
> **核心项目**：图书馆智能客服系统（AI Agent + RAG）
> **出题依据**：完全基于简历正文（教育经历 + 项目经历 4 大模块 + 自我评价），并按简历措辞逐条展开。
> **特别提示**：第 8 类「简历拔高点核验」是**高风险题**，直接对照实际代码（已在本仓库先行核对）。面试官若当场翻你代码，这些题最容易让你"被戳穿"。建议用"诚实收窄"口径准备（详见 `拷问问题集-第4次-高压实战与简历真实性.md`）。
> **用法**：先按类自测，标出"答不上来"的题，再回到项目代码/需求文档补强。

## 一、项目概览与架构（10 问）

1. 用一句话介绍你的图书馆智能客服系统的整体架构与数据流。
2. 为什么选择 RAG 而不是纯 LLM 或纯微调来回答图书馆咨询？
3. 用户从发消息到收到回答，请完整描述一次请求的端到端链路。
4. 你说"压降人工咨询量"，这个目标你是怎么量化衡量的？
5. 你提到"低幻觉、可溯源"，请解释"可溯源"在你的系统里具体如何实现。
6. 如果让你在 1 分钟内向不懂技术的馆长介绍这个项目，你会怎么说？
7. 这个项目里最复杂 / 最难的一个模块是哪个？为什么？
8. 你独立完成项目，遇到的最大技术卡点是什么，怎么解决的？
9. 假如图书馆要接入微信 / 小程序，你的架构需要做哪些改造？
10. 你如何证明系统"显著"提升了效率，而不只是"做出来了"？

26. 你如何用 Prompt 约束"基于检索内容回答 + 引用来源"？给一个 prompt 片段。
